## ❓ What is an AAS passport?

### `v4_fewshot`  · prompt 758 tok · output 83 tok

An AAS passport is a JSON file that stores per-stage configuration, measurements, and an append-only RunHistory for each dataset in the pipeline. It is located in AAS/datasets/<date>/ and provides a detailed record of the dataset's journey through the pipeline stages.

Where: AAS tab on the dashboard or AAS/datasets/<date>/CA_Modul-OD_dataset_<name>.json.

### `v5_German`  · prompt 781 tok · output 78 tok
