# Paper Visualisation

Scripts that produce the figures used in publications.

| Script | Output |
|---|---|
| `visualisation.py` | general result plots |
| `visualisation_fig2.py` | paper figure 2 |
| `vis_fig3.py` | paper figure 3 |
| `saliency_vis.py` | saliency-map visualisations of trained detectors |

`images/` and `runs/` hold generated outputs and are git-ignored — re-run the
scripts to regenerate them.
